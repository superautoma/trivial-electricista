# Trivial Electricista — PWA

Esta versión corrige y fuerza la actualización de las explicaciones técnicas, además de limpiar duplicados exactos durante la inicialización de IndexedDB.

Archivos que deben quedar en la raíz de GitHub Pages:
- index.html
- manifest.webmanifest
- sw.js
- icon-192.png
- icon-512.png

Después de subirlos, abre la PWA y recarga una vez. Si Chrome conserva la versión anterior, abre la URL en una pestaña de incógnito o borra los datos del sitio y vuelve a abrirla.
