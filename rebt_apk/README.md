# REBT Cuestionados APK

Proyecto Python + Kivy para estudiar el Reglamento Electrotecnico de Baja Tension.

Esta rama esta aislada de la version estable de Trivial Electricista y se usa solo como entorno de compilacion del APK.

- Codigo principal: rebt_apk/main.py
- Configuracion Android: rebt_apk/buildozer.spec
- APK: se genera como artefacto de GitHub Actions.
